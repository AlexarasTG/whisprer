# Whisprer

![Whisprer app icon](app/Whisprer/Whisprer/Assets.xcassets/AppIcon.appiconset/icon_512x512.png)

Whisprer is a macOS menu bar dictation app for developers.

Core loop:

> Hold `Right Option` → speak → release → text appears
